## wxmang 文章合集

本仓库原始数据来自豆瓣小组“管理实践与学习”中分享的[mdb文件](https://www.douban.com/group/topic/74970906/)，包含忙总在西西河、丰言、茶馆、豆瓣四个时期的所有文章和问答。

我将原始数据二次整理，按照“文章+问答”的格式分列成一个个独立的网页，网址是 https://wxmang.site 。数据未做删改，仅在网页端css隐藏了重复引用的内容。（不过因为数据量很大，难免会有错漏，欢迎提issue指出问题。）

网站还具有[搜索功能](https://wxmang.site/search)，欢迎使用并反馈。

离线下载后可以离线部署网站，在根目录下执行 `python -m http.server 8000`，然后访问 http://localhost:8000 即可。
